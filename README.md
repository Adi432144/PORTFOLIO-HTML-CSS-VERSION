## Key Highlights

- **Inspector Component UI:** Modeled after IDEs and game editor panels with real-time CSS pulse status badges and terminal simulation blocks.
- **Zero-JS Dependency Architecture:** Built exclusively with semantic HTML5 and vector SVG symbol sprites for zero script latency and maximum security.
- **Adaptive Responsive Layout:** Features a fixed sidebar navigation for desktop screens that smoothly transitions into an elevated sticky navigation bar on mobile viewports.
- **Performance Optimized:** Employs CSS custom properties, system font fallbacks, hardware-accelerated transitions, and dynamic glassmorphism effects.

## 🛠️ Quick Local Setup
1. **Clone the repository:**
   ```bash
   git clone https://github.com/Adi432144/PORTFOLIO-HTML-CSS-VERSION.git
   ```

2. **Navigate into the directory:**
   ```bash
   cd PORTFOLIO-HTML-CSS-VERSION
   ```

3. **Launch in browser:**
   Open `index.html` directly in any browser or serve via Live Server[cite: 2].
   ```bash
   npx serve .
   ```
